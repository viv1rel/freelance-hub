# Руководство по ручному тестированию FreelanceHub

Этот документ — пошаговая инструкция для полной проверки всех функций платформы.
Все шаги выполняются последовательно в браузере на чистой базе данных.

---

## Тестовые данные ЮKassa (тестовый режим)

| Поле | Значение |
|---|---|
| Номер карты | `1111 1111 1111 1026` |
| Срок действия | `12/26` |
| CVV | `000` |
| Код 3D-Secure | `1234` (или нажать «Успешно» на тестовой странице) |

## 1. Запуск проекта

**1.1.** Открой терминал в папке проекта и запусти контейнеры:
```bash
cd ~/freelance-hub
docker compose up -d
```
**Ожидаемый результат:** все 5 контейнеров в статусе `running` (`app`, `nginx`, `mysql`, `redis`, `mailpit`).

**1.2.** Установи зависимости и выполни миграции:
```bash
docker compose exec app composer install
docker compose exec app php artisan migrate
docker compose exec app npm run build
```
**Ожидаемый результат:** в конце каждой команды нет ошибок. Миграции выводят список выполненных таблиц.

**1.3.** Открой браузер и перейди на [http://localhost](http://localhost).

**Ожидаемый результат:** открывается лендинг FreelanceHub с описанием платформы, кнопками «Войти» и «Начать бесплатно».

## 2. Регистрация и вход

### Регистрация

**2.1.** Нажми кнопку **«Начать бесплатно»** на лендинге.

**2.2.** Заполни форму регистрации:
- Имя: `Иван Тестов`
- Email: `ivan@test.ru`
- Пароль: `password123`
- Подтверждение пароля: `password123`

**2.3.** Нажми кнопку **«Зарегистрироваться»**.

**Ожидаемый результат:** автоматический редирект на `/dashboard`. Отображается дашборд с нулевыми метриками. В левом меню видны разделы: Дашборд, Проекты, Задачи, Время, Клиенты, Счета, Подписка, Настройки.

---

### Выход и повторный вход

**2.4.** Нажми на имя пользователя в правом верхнем углу → **«Выйти»**.

**Ожидаемый результат:** редирект на страницу входа.

**2.5.** Введи:
- Email: `ivan@test.ru`
- Пароль: `password123`

Нажми **«Войти»**.

**Ожидаемый результат:** успешный вход, редирект на `/dashboard`.

---

### Двухфакторная аутентификация (2FA)

**2.6.** Перейди в **Настройки** (левое меню) → вкладка **«Безопасность»** (или `/settings/security`).

**2.7.** Нажми **«Включить двухфакторную аутентификацию»**.

**Ожидаемый результат:** появляется QR-код.

**2.8.** Открой приложение **Google Authenticator** (или Authy) на телефоне → нажми `+` → «Сканировать QR-код» → отсканируй QR-код на экране.

**Ожидаемый результат:** в Google Authenticator появляется аккаунт «FreelanceHub» с 6-значным кодом, который меняется каждые 30 секунд.

**2.9.** Введи текущий 6-значный код из приложения в поле на странице → нажми **«Подтвердить»**.

**Ожидаемый результат:** появляется сообщение «2FA включена».

**2.10.** Выйди из аккаунта (шаг 2.4).

**2.11.** Войди снова (email + пароль, шаг 2.5).

**Ожидаемый результат:** после ввода пароля открывается дополнительная страница с полем «Код подтверждения».

**2.12.** Введи актуальный код из Google Authenticator → нажми **«Подтвердить»**.

**Ожидаемый результат:** успешный вход, редирект на `/dashboard`.

**2.13.** Перейди в Настройки → Безопасность → нажми **«Отключить 2FA»** → введи код из приложения для подтверждения.

**Ожидаемый результат:** 2FA отключена, при следующем входе код запрашиваться не будет.

## 9. Оплата через ЮKassa

> Для этого раздела требуется запущенный localtunnel и настроенный webhook (см. README.md).
> Тестовые реквизиты карты: `1111 1111 1111 1026`, срок `12/26`, CVV `000`.

### Оплата счёта клиентом

**9.1.** На странице счёта найди раздел **«Ссылка для оплаты»** → скопируй ссылку вида `/pay/invoice/{token}`.

**9.2.** Открой эту ссылку в режиме инкогнито (имитация клиента, получившего письмо).

**Ожидаемый результат:** страница оплаты счёта с суммой к оплате и кнопкой «Оплатить через ЮKassa».

**9.3.** Нажми **«Оплатить через ЮKassa»**.

**Ожидаемый результат:** редирект на страницу оплаты ЮKassa (yookassa.ru).

**9.4.** На странице ЮKassa выбери способ оплаты **«Банковская карта»** и введи тестовые данные:
- Номер карты: `1111 1111 1111 1026`
- Срок: `12/26`
- CVV: `000`
- Имя: любое, например `IVAN TESTOV`

Нажми **«Оплатить»**.

**9.5.** На странице 3D-Secure введи код `1234` (или нажми кнопку «Оплатить успешно» в тестовом интерфейсе).

**Ожидаемый результат:** ЮKassa отправляет webhook на твой сервер и перенаправляет обратно на страницу успешной оплаты FreelanceHub.

**9.6.** Вернись в основной браузер (войди как `ivan@test.ru`), открой счёт.

**Ожидаемый результат:**
- Статус счёта изменился на **«Оплачен»**
- В разделе «Транзакции» счёта появилась запись с суммой платежа и статусом «succeeded»

**9.7.** Проверь в БД (опционально):
```bash
docker compose exec mysql mysql -ufreelancehub -psecret -e "SELECT * FROM transactions ORDER BY id DESC LIMIT 5;" freelancehub
```

## 11. Дашборд

Перейди в раздел **«Дашборд»** (`/dashboard`).

**11.1.** Проверь наличие всех блоков:

| Блок | Ожидаемое значение |
|---|---|
| Доход за месяц | Сумма оплаченных счетов за текущий месяц (например, 70 200 ₽) |
| Доход за квартал | Та же сумма или больше |
| Активные проекты | Количество проектов со статусом «Активный» |
| Незакрытые счета | Сумма неоплаченных счетов |
| Топ клиентов | Список клиентов с суммой выручки |

**11.2.** Проверь график **«Доход по месяцам»**:
- Отображаются последние 12 месяцев
- Текущий месяц показывает ненулевое значение (сумма оплаченного счёта)
- При наведении на столбец показывается точная сумма
